# Tulsa vs Series

Tulsa takes on abstract challenges, systemic problems, and industry-wide issues.

Not city vs city — that's **Head to Head**.

This is Tulsa vs the problem itself.

## Format
Each episode tackles a challenge everyone talks about but few solve:
- The Skills Gap
- Legacy Systems
- Brain Drain
- The Productivity Plateau
- The Housing Crisis
