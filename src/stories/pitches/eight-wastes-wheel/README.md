# The 8 Wastes Wheel

## Hook
"The average manufacturer spends only 25-35% of their time on activities that actually create value. The rest? Pure waste."

## Target Audience
- Manufacturing leaders
- Operations managers
- Lean practitioners
- Industrial engineers

## Visualization Concept
Interactive/animated breakdown of where time goes in a typical factory. Show 100 hours of production time and color-code: only 25-35 hours are value-added. The rest is waste categories (TIMWOODS):
- **T**ransport
- **I**nventory
- **M**otion
- **W**aiting
- **O**verproduction
- **O**ver-processing
- **D**efects
- **S**kills underutilization

## Key Data Points
- Average manufacturer operates at only 25-35% value-added time
- 65-75% of activity is waste (LEI estimates)
- Waiting time accounts for ~30% of total production time
- Defect rates in non-lean: 3-5% vs <0.1% for lean practitioners

## Data Sources
- Lean Enterprise Institute (value-added ratios)
- Industry surveys (AME, Shingo Prize, IndustryWeek)
- Toyota Production System benchmarks

## CTA Angle
"This is where software changes everything. Real-time visibility turns hidden waste into actionable data."
