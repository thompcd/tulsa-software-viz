# The Reshoring Wave

## Hook
"350,000+ manufacturing jobs announced for return to the U.S. since 2020. Where are they going?"

## Target Audience
- Manufacturing executives
- Economic developers
- Supply chain professionals
- Policy makers

## Visualization Concept
Animated map of U.S. showing reshoring job announcements by state/region over time. Highlight Oklahoma/Tulsa's share and growth.

Options:
- Choropleth map with timeline slider
- Flow diagram: jobs leaving Asia → U.S. regions
- Bar race chart of states by reshoring jobs

## Key Data Points
- 350,000+ manufacturing jobs announced for return since 2020
- Reshoring Initiative tracking data
- State-by-state breakdown
- Oklahoma's position in the trend

## Data Sources
- Reshoring Initiative (primary)
- NAM regional data
- State economic development announcements

## CTA Angle
The reshoring trend is real. Companies need manufacturing software that works — not legacy systems designed for a different era.
